# Folding@home (LinuxServer)

Dieses Add-on führt das Folding@home Image von LinuxServer.io aus, welches eine integrierte WebUI besitzt.

## Zugriff
Nach dem Starten des Add-ons kannst du über den angegebenen Port (Standard: 7396) auf das Web Interface zugreifen, um deine Identität und Teams einzustellen.
